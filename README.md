# Secure Banking Application

## Project Description
A secure, console-based Java banking application built to demonstrate robust Object-Oriented Programming (OOP) principles and secure coding practices[cite: 1]. It features secure user authentication, account management, transaction processing, and flat-file data persistence[cite: 1].

## Features Implemented
* **User Authentication:** A secure login and registration mechanism to protect user credentials[cite: 1].
* **Account Management:** Automated bank account creation upon user registration and real-time balance checking[cite: 1].
* **Transactions:** Secure deposit and withdrawal functionalities with strict validation checks[cite: 1].
* **Data Persistence:** Automatic saving and loading of user credentials and account data using text files (`users.txt` and `accounts.txt`), ensuring data survives application restarts[cite: 1].
* **Maintainable Code Architecture:** Clean, modular object-oriented design emphasizing robust input handling and separation of concerns.
